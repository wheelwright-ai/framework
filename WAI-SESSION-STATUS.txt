HOW TO USE
================================================================================

To log an observation:
  from wai.observation import log_observation
  log_observation(action_id="...", ..., session_id="...")

To load SSH config:
  from wai.config import get_config
  config = get_config()
  author = config.get_git_author()

To run git with observation:
  from wai.utils.git import create_git_ops
  git = create_git_ops()
  obs = git.push(session_id="...")

To get session briefing:
  from wai.briefing import build_session_briefing
  briefing = build_session_briefing(session_id="...")

See: OBSERVATION-QUICK-REFERENCE.md for more examples
