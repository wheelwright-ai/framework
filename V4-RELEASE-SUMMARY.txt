WHAT'S NEW

🎡 Wheel-Based Teaching & Learning
   Before: Teach/learn one project at a time
   After:  Teach/learn all 19+ projects in wheel with one command

📋 Hub Registry Integration  
   Reads from: ../hub/registry/wheel-projects.json
   Shows: All projects in the wheel
   Auto: Caches for performance

🔍 Intelligent Discovery
   Finds: Framework root automatically
   Locates: Hub at ../hub (relative to framework)
   Loads: Hub registry with all projects
   Falls back: Gracefully if registry missing
