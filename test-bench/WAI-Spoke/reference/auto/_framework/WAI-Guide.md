# WAI-Guide.md
**Version:** 3.1.0
**Purpose:** Quick-start guide for AI assistants joining Wheelwright projects

## Welcome to Wheelwright Framework

You are joining a project using **Wheelwright** for universal context persistence.

## Priority 0: Session Start

1. Run /wai command
2. Check git status
3. Ask: Continue or start fresh?

## Priority 1: Behavioral Guidelines

Follow the skills system. Skills are the source of truth for behavioral rules.

## Priority 2: Decision Points

### Complexity Gate
Planning required if:
- Changes affect 2+ files, OR
- Implementation requires 6+ steps

## Project Context

Project: Wheelwright Framework (v3.1.0)

## Collaboration Model (ADAPTIVE)

| Task Type | Your Role |
|----------|-----------|
| Small fixes | Proceed autonomously |
| Significant features | Propose plan → Get approval → Implement |

## Session Commands

- /wai - Unified briefing
- /wai-status - Health check
- /wai-time - Token usage
- /wai-rules - Show boundaries
- /wai-closeout - End ceremony
- /wai-shipit - Closeout + commit
- /wai-teach - Pull hub learnings
- /wai-learn - Push high-impact signals
- /wai-red-light - Inspect autosave
- /wai-green-light - Resume from checkpoint
