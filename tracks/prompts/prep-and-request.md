# Prep-and-Request Prompt

Use this when you have specific context (e.g., code snippets, project documents) that you want to ensure are captured in the Track file before closeout.

---

## The Prompt

"We are preparing to close this session. I will provide some key context for you to review and then I will request the structured Track file.

1. **Review these files/documents:** [Insert files here]
2. **When you are ready, I will send the closeout command.**
3. **The goal is a high-fidelity Track file** that captures our thinking and progress on these specific items.

Acknowledge that you have received this context and are ready for the closeout command."
