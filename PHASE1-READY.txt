HOW TO USE IT RIGHT NOW (WSL)
================================================================================

Interactive Menu (Default - No Arguments):
   cd /home/mario/projects/wheelwright-ai/framework
   python3 -m wai.cli.main
   
   You'll see: Welcome banner + wagon wheel + interactive menu
   Choose options with numbers or letters
   Follow the prompts for guided setup

Command-Line (Power Users - With Arguments):
   python3 -m wai.cli.main init hub --name MyHub
   python3 -m wai.cli.main learn spoke ProjectA
   python3 -m wai.cli.main teach spoke ProjectA
   python3 -m wai.cli.main stats spoke ProjectA --json

Easy Alias Setup (One-Time):
   echo 'alias wai="python3 /home/mario/projects/wheelwright-ai/framework/WAI-CLI"' >> ~/.bashrc
   source ~/.bashrc
   wai  # Now works from anywhere!
