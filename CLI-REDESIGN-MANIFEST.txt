SUMMARY OF CONTENTS
═══════════════════════════════════════════════════════════════════════════════

VISION
  • Verb-noun CLI (wai learn spoke ProjectA)
  • Iconic wagon wheel animation (calling card)
  • Skills-driven menus (auto-updated)
  • Node-centric design (hub, spoke, group)
  • Non-breaking transition (4 phases, 6 weeks)

CORE VERBS
  ✅ init     - Create hub or spoke
  ✅ learn    - Push signals to hub
  ✅ teach    - Pull templates from hub
  ✅ stats    - View metrics (Phase 2)
  ✅ review   - Inspect state (Phase 2)
  ✅ absorbe  - Process seed folders (Phase 2)

NODE TYPES
  ✅ hub      - Central knowledge repository
  ✅ spoke    - Individual project/workspace
  ✅ group    - Organizational collection (Phase 2)

DATA ARCHITECTURE
  ✅ WAI-Skills.jsonl    - Command definitions (source of truth)
  ✅ WAI-State.json      - Node state (read/write)
  ✅ WAI-Signals.jsonl   - Learning signals
  ✅ Lugs                - CLI specifications (hidden from other objects)
  ✅ config.json         - UI preferences (Phase 4)

INNOVATION
  ✅ Wagon wheel = visual brand identity
  ✅ Skills-driven = eliminates menu/skill sync problems
  ✅ Verb-noun = power users + discovery
  ✅ Node-centric = aligns with framework philosophy
  ✅ Non-breaking = safe 6-week transition
