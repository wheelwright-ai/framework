# Hub

Public hub-side framework assets.

This tree now separates reusable hub behavior from stateful hub runtime content.

Current public ownership:

- `codebase/skills/` for hub-specific behavior and overrides
- `codebase/advisors/` for reusable hub advisor schemas
- `teachings/` for hub-distributed framework teachings

Legacy stateful files still under the top-level `hub/` path are transitional and
should not be treated as the long-term public surface.
