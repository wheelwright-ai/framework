# Assessor Schema Reference

**Schema Version:** 1.0.0  
**Location:** `hub/advisors/assessor/schema/`  
**Maintained by:** Wheelwright Framework (Assessor advisor)

---

## Overview

The Assessor produces two artifact types:

1. **Assay** — the portable unit of truth for community contribution. A single model performance observation from a real work session.
2. **Model Registry Entry** — owned by Navigator, referenced by Assessor when building Assays. Documents provider models, pricing, and capability metadata.

---

## 1. Assay (`assay-v1.0.0.json`)

### Purpose

An Assay records what happened when a specific model did specific work. It is the smallest reusable unit of performance data — enough to feed local Navigator recommendations and, when stripped of identifying fields, to contribute to the wheelwright.ai community pool.

### `_wai_meta` Strip Policy

**Before contributing an Assay to wheelwright.ai, the `_wai_meta` block must be removed.**

`_wai_meta` contains `session_id` and `spoke_id` — identifiers that must not leave the fleet. The Assessor's contribution packaging step (Phase 2) enforces this strip. No manual intervention required, but the schema documents the requirement here so downstream code can assert its absence before upload.

### `assay_type` Distinction

| Value | Meaning |
|---|---|
| `individual` | Generated by a single spoke from one real session. `contributor_count` in provenance is null. |
| `community` | Merged cohort record from wheelwright.ai. Represents aggregated data from multiple contributing fleets. `contributor_count` reflects the number of merged sources. |

Individual Assays are what spokes generate. Community Assays are what Navigator receives back from wheelwright.ai as an enrichment feed.

### `latency_ms` Best-Effort Note

`latency_ms` is **not in `required[]`** and accepts `null`. Latency measurement at the hook/agent level is unreliable — the Claude Code harness does not expose per-turn timing. Record it when available from API response headers or explicit instrumentation; omit it otherwise. `latency_bucket` can still be populated from a rough estimate if `latency_ms` is null.

### Field Reference

| Field | Type | Required | Description |
|---|---|---|---|
| `schema_version` | string | yes | Always `"1.0.0"`. Increment only on breaking changes. |
| `assay_id` | string | yes | Unique identifier (UUID v4 recommended). |
| `assay_type` | enum | yes | `individual` or `community`. See distinction above. |
| `created_at` | string (date-time) | yes | ISO 8601 creation timestamp. |
| `provider` | string | yes | Provider slug (e.g. `anthropic`, `openai`). |
| `model_id` | string | yes | Canonical API model identifier. |
| `model_family` | string\|null | no | Family grouping for cohort analysis. |
| `provider_tier` | enum | yes | `frontier`, `capable`, `economy`, `local`. |
| `work_type` | enum | yes | `coding`, `debugging`, `writing`, `analysis`, `planning`, `refactoring`, `testing`, `ops`, `research`, `other`. |
| `complexity` | integer 1-5 | yes | Perceived task complexity. 1 = trivial, 5 = highly complex. |
| `quality_score` | number 0-5\|null | no | Subjective output quality. |
| `rework_rate` | number 0-1\|null | no | Proportion of output requiring rework. |
| `latency_ms` | integer\|null | no | Response latency in ms. Best-effort; null acceptable. |
| `latency_bucket` | enum\|null | no | `ultra_fast` (<500ms), `fast` (500ms-2s), `moderate` (2-10s), `slow` (10-30s), `very_slow` (>30s). |
| `tokens_in` | integer\|null | no | Input token count. |
| `tokens_in_bucket` | enum\|null | no | `tiny` (<1k), `small` (1k-5k), `medium` (5k-20k), `large` (20k-50k), `xlarge` (>50k). |
| `tokens_out` | integer\|null | no | Output token count. |
| `tokens_out_bucket` | enum\|null | no | Same scale as `tokens_in_bucket`. |
| `cost_tier` | enum | yes | `negligible` (<$0.001), `low` ($0.001-0.01), `moderate` ($0.01-0.10), `high` ($0.10-1.00), `premium` (>$1.00). |
| `confidence` | enum | yes | `high` = direct human feedback, `medium` = inferred from session signals, `low` = estimated. |
| `provenance.spoke_id` | string\|null | no | Originating spoke. Stripped before community contribution. |
| `provenance.session_id` | string\|null | no | Originating session. Stripped before community contribution. |
| `provenance.contributor_count` | integer\|null | no | Community Assays only — number of merged fleets. |
| `_wai_meta` | object\|null | no | Internal envelope. **Strip before contribution.** Contains `session_id`, `spoke_id`, `generated_at`, `contributed_at`. |

### Schema Evolution

`schema_version` enables forward compatibility. Upgrade rules:

- **Patch** (1.0.x): Add optional nullable fields. Old readers ignore unknown fields (note: schema uses `additionalProperties: false` — validators must be updated on patch bumps).
- **Minor** (1.x.0): Add optional sections or relax constraints. Backwards compatible for readers.
- **Major** (x.0.0): Breaking change. Old Assays cannot be validated against new schema without migration. Document migration path in this file under a `## Migration` section.

## 2. Model Registry Entry (`model-registry-v1.0.0.json`)

### Purpose

Defines the structure of a single entry in Navigator's model catalog. The registry is **owned by Navigator** — Assessor references `model_id` values from it but does not write to it. Documented here because Assay `model_id` values must resolve to a registry entry for cohort grouping.

### Field Reference

| Field | Type | Required | Description |
|---|---|---|---|
| `provider` | string | yes | Provider slug (e.g. `anthropic`, `openai`). |
| `model_id` | string | yes | Canonical API model identifier. |
| `model_family` | string\|null | no | Family grouping (e.g. `claude-sonnet`). |
| `display_name` | string\|null | no | Human-readable name (e.g. `Claude Sonnet 4.6`). |
| `provider_tier` | enum | yes | `frontier`, `capable`, `economy`, `local`. |
| `context_window` | integer | yes | Maximum context window in tokens. |
| `max_output_tokens` | integer\|null | no | Maximum output tokens per response. |
| `known_strengths` | string[] | no | Descriptors (e.g. `["coding", "long-context"]`). |
| `pricing_input_per_1m_tokens` | number\|null | no | Input price USD per 1M tokens. |
| `pricing_output_per_1m_tokens` | number\|null | no | Output price USD per 1M tokens. |
| `availability_regions` | string[] | no | Region codes. Empty = globally available. |
| `deprecated_at` | string (date)\|null | no | ISO 8601 date of deprecation/EOL. |
| `notes` | string\|null | no | Free-text model notes. |

## Examples

- `examples/assay-example-001.json` — individual Assay, claude-sonnet-4-6, coding work, complexity 3.

To validate an Assay example:

```bash
python3 -c "
import json, jsonschema
schema = json.load(open('hub/advisors/assessor/schema/assay-v1.0.0.json'))
example = json.load(open('hub/advisors/assessor/schema/examples/assay-example-001.json'))
jsonschema.validate(example, schema)
print('VALID')
"
```
