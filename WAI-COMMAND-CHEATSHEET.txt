=====================================================================
FLAGS & OPTIONS
=====================================================================

--priority {high|normal|low}
   Set signal priority
   Default: normal
   Example: wai learn spoke ProjectA --priority high

--force, -f
   Skip confirmation prompts
   Example: wai learn spoke ProjectA --force

--json
   Output as JSON (machine-readable)
   Example: wai learn spoke ProjectA --json

--format {table|json|text}
   Output format for stats/review
   Default: table
   Example: wai stats spoke ProjectA --format json

--deep
   Detailed analysis for review
   Example: wai review spoke ProjectA --deep

--all, -a
   Show detailed breakdown for stats
   Example: wai stats spoke ProjectA --all

--help
   Show help for command
   Example: wai learn --help

--version
   Show CLI version
   Example: wai --version
